# JobPilot: инструкция по запуску

Сначала всё проверяем на вашем Mac, потом переносим на сервер. Файлы `.env`, `accounts.toml` и письма
`data/letters/*.txt` уже заполнены. Ключи, токены и сессии никому не отправляйте и в git не кладите.

## 0. Что уже сделано

- [x] `.env`: ключи Telegram, токен бота, ваш id, папка `Work`, почта для hh
- [x] `accounts.toml`: два аккаунта (php и go), названия резюме, слова `include` / `exclude`
- [x] письма: `data/letters/{php,go}_{ru,en}.txt`

## 1. Установка (один раз)

Нужен Python 3.11 или новее (`python3 --version`, если старше: `brew install python@3.12`).

```
cd ~/Desktop/JobPilot
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
playwright install chromium
```

В следующих окнах терминала сначала `cd ~/Desktop/JobPilot && source .venv/bin/activate`.

## 2. Telegram

1. Запасной аккаунт (юзербот): вступите в чаты с вакансиями и положите их в папку **Work**
   (название должно совпадать с `TG_FOLDER`).
2. Откройте своего бота в Telegram и нажмите `/start`.
3. `jobpilot login`: введите номер запасного аккаунта и код из Telegram.
4. `jobpilot run` и оставьте окно открытым.
5. В боте: `/filters` (проверить слова), `/mode realtime` или `/mode digest`, `/digest_time 09:00`.
   Новая подходящая вакансия из чата пришлёт карточку (realtime) или попадёт в `/digest`.

Новые чаты в папке подхватываются сами в течение 5 минут. Папка читается с запасного аккаунта.

## 3. hh.ru

1. `jobpilot hh-login php` и `jobpilot hh-login go`: откроется окно, войдите в аккаунт вручную
   и нажмите Enter в терминале.
2. `jobpilot hh-search php`: должен напечатать, сколько вакансий нашёл каждый запрос.
   Ошибку или ноль пришлите мне.
3. `jobpilot hh-dump php <ссылка на вакансию>`: сохранит страницы в `data/dumps/php/` и ничего не отправит.
   Когда попросит, сами нажмите «Откликнуться», чтобы открылось окно отклика (письмо не отправляйте),
   и нажмите Enter. Эти файлы (3 `.html` и 3 `.png`) пришлите мне, по ним я проверю кнопки.
   В них видна ваша переписка с работодателями, просмотрите перед отправкой.
4. `jobpilot hh-run php`: пробный прогон, только печатает, на что откликнулся бы.
5. После моей проверки кнопок: в `accounts.toml` поставьте `start_limit = 1` и запустите
   `jobpilot hh-run php --live`. Отклик идёт только с 09:00 до 21:00 по Еревану.
6. Бот: `/resume ru` или `/resume en` выбирает резюме и язык письма.

## 4. Сервер

1. VPS в Европе, Ubuntu, 2 ГБ памяти, с вашим публичным ключом (`~/.ssh/id_ed25519.pub`).
2. Telegram-часть: `scripts/deploy.sh root@IP-СЕРВЕРА`, затем команда входа юзербота, которую скрипт
   напечатает в конце.
3. hh-часть едет вместе с остальным (в образе есть Chromium). Перед `deploy.sh` сохраните входы:
   `jobpilot hh-export php` и `jobpilot hh-export go`. Скрипт `deploy.sh` сам скопирует
   `data/browser/*/state.json` на сервер. Сам профиль браузера не копируется, он не переносится с Mac.
   Если hh с сервера покажет капчи или попросит войти заново, понадобится прокси или вход заново.
4. На сервере отклики идут каждый час с 09:00 до 21:00 по Еревану (php в :05, go в :35),
   напоминания раз в день около 13:00. Команда бота `/pause` останавливает и hh-часть.

## 5. Что присылать мне

Файлы из `hh-dump`, вывод `hh-search` и `hh-run` (или текст ошибки), а если бот молчит, то что написано
в терминале у `jobpilot run`.

Не присылать никому: `.env`, `data/userbot.session`, папку `data/browser`, приватный ключ SSH
(файл без `.pub`), пароли серверов.

## 6. Код в GitHub

Когда всё заработает: `git add -A && git commit -m "Initial version" && git push -u origin main`.
`.env`, `accounts.toml` и сессии в `.gitignore`.
